# zapix-cli

CLI tool for scaffolding and generating Zapix projects.

## Installation

```bash
npm install -g zapix-cli
```

## Usage

```bash
# Create a new Zapix project
zpx create my-app

# Or use the full command name
zapix create my-app
```

## Commands

- `create <project-name>` — Scaffold a new Zapix project from a starter template
